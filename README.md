# 静时

静时是一个 macOS 菜单栏计时器，用来做专注和休息。窗口可以缩成贴在屏幕上的小浮窗，也可以展开成完整面板。它不联网，不安装第三方库，数据只保存在本机。

界面采用宋韵青瓷：宣纸米白背景、青瓷绿按钮和进度、宋体标题，以及一枚很小的朱砂印记。背景有极淡纸纹，完整窗口底部有一小段枝叶线稿。这些都由程序绘制，不依赖图片或网络。

## 环境要求

- macOS 14 或更新版本
- 已安装 Xcode 命令行工具（提供 `swiftc` 和 `codesign`）

系统自带「宋体-简」（Songti SC）。不需要单独下载字体。

## 获取项目

```sh
git clone git@github.com:gpqhl0071/QuietTimer.git
cd QuietTimer
```

仓库里是源码和说明。应用包不提交到 Git，克隆后运行一次脚本即可。

## 编译并打开

在项目目录执行：

```sh
./build.sh
```

脚本会创建 `QuietTimer.app`，编译 `main.swift`，完成本机签名并打开。窗口和菜单里的名字仍是「静时」。

改过源码后，再运行一次 `./build.sh`。如果菜单栏里已经有静时，先选择「退出静时」，让当前计时写入本机，再运行脚本。

如果系统仍提示无法打开，右键 `QuietTimer.app`，选择「打开」。

## 日常用法

启动后默认是置顶小浮窗，尺寸 **224 × 184**。它会浮在其他应用、桌面和全屏页面之上。空白处可以拖动窗口；按钮、输入框和弹层不会抢走拖动。

每次重新打开都会回到置顶小浮窗。取消置顶只影响当前这一次，不会重置正在进行的计时。

### 小浮窗

从上到下是：

- 模式名，以及「已暂停」或「已完成」
- 大号倒计时，下方是「设置时长」
- 细进度条、开始/暂停、重置

右上角滑杆图标打开设置，图钉取消置顶并展开完整窗口。

### 完整窗口

取消置顶后窗口变为 **360 × 594**。这里可以：

- 在「专注」「短休息」「长休息」之间切换
- 查看圆窗进度、状态和倒计时
- 填写这一刻想做的事
- 开始、暂停、继续，或重新计时
- 查看今天已完成的专注次数

外圈细线是装饰，内圈才表示真实进度。主按钮是当前这段的主要操作，旁边的重置按钮权重更低。

### 开始、暂停、继续和重置

- 还没开始时，主按钮是「开始专注」或「开始休息」。
- 计时中可以暂停。暂停后主按钮变为「继续」，时间停住。
- 这段已经走完时，主按钮变为「去休息」或「回到专注」。下一段需要自己点开始，不会自动开表。
- 计时还没开始，或刚刚结束时，重置会立刻回到本段时长。
- 正在计时，或暂停在中途时，重置会先询问。选择「重新开始」才清空这段进度；选择「取消」则原计时继续。未完成的专注不会计入今日次数。

### 自由输入时长

点击大号时间，或它下面的「设置时长」：

1. 填写分钟和秒。单位「分」「秒」一直显示在输入框旁边。
2. 点击「开始倒计时」。

允许的范围是 **1 秒到 999 分 59 秒**。下面这些输入不能开始，弹层会写出原因：

- 分钟或秒留空
- 总时长为 0
- 负数，或带有非数字字符
- 秒数小于 0 或大于 59
- 分钟小于 0 或大于 999

已经有进度时，主按钮文字变成「替换并开始」。确认后用新时长重开；点「取消」则原来的倒计时继续走，编辑期间也不会暂停。

自定义时长只属于当前模式。重置会回到这个自定义时长，退出重开也会保留。切换模式，或进入下一段时，恢复那个模式在设置里的预设分钟数。

### 设置

设置里可以调整：

| 项目 | 范围 | 何时生效 |
|---|---|---|
| 专注、短休息、长休息的预设 | 1–120 分钟 | 下一段计时 |
| 结束提示音 | 开或关 | 下一次结束 |
| 窗口不透明度 | 35%–100%，默认 70% | 立刻 |

不透明度只让背景变透，倒计时、按钮和输入内容保持清晰。预设时长不会改掉已经开始的这一段。

### 菜单栏

关闭窗口后，静时仍留在菜单栏里计时。

- 计时中：显示剩余时间
- 空闲：显示计时标记
- 完成后：显示「✓ 静时」

点开菜单可以「打开静时」「开始 / 暂停」或「退出静时」。彻底退出会先保存进度。

## 计时规则

默认预设：

| 模式 | 默认时长 |
|---|---|
| 专注 | 25 分钟 |
| 短休息 | 5 分钟 |
| 长休息 | 15 分钟 |

- 只有专注完成才会增加「今天已完成」的次数。休息完成不计数。
- 每完成 4 次专注，下一次从专注进入的休息会建议为长休息。这个建议在你点「去休息」时生效。
- 到点后播放系统「Glass」提示音（可在设置里关闭），并请求系统提醒。
- 电脑睡眠或应用退出期间不会响铃。唤醒或重新打开后，按原来的结束时间把状态补上：到点则记为完成。
- 日期变更后，今日完成次数从 0 重新计算。

## 本机会记住什么

这些内容写在用户偏好 `local.penggao.quiettimer` 的 `clock` 项里：

- 当前模式、剩余时间、本段总时长和是否已完成
- 正在运行时的结束时间
- 任务文字
- 三种模式的预设分钟数
- 自定义时长
- 提示音开关和不透明度
- 今日完成次数及其日期

窗口位置由系统按窗口名 `QuietTimerWindow` 记住。置顶状态不保存，下次打开仍是小浮窗。

偏好文件通常在：

```text
~/Library/Preferences/local.penggao.quiettimer.plist
```

删除这个文件会回到默认的 25 / 5 / 15 分钟，并清空任务和今日次数。正在运行时先退出静时，再删文件。

## 项目结构

```text
QuietTimer/
├── README.md      本说明
├── build.sh       一键编译、签名并打开
├── main.swift     全部源码：计时、界面、窗口和菜单栏
├── 使用说明.md    简要使用笔记
└── .gitignore     忽略本机编译出的应用包
```

计时逻辑在 `ClockModel`，界面在 `TimerView`。改外观时保持 `ClockModel` 的开始、暂停、重置和完成规则不变。

## 常见情况

**改完源码没有变化。** 先从菜单栏退出静时，再运行 `./build.sh`。

**小浮窗挡住内容。** 把不透明度调低，或拖到屏幕边缘。展开和弹层会尽量留在屏幕可见范围内。

**睡眠结束后没有听到铃声。** 睡眠中不会响。打开或唤醒后，如果结束时间已过，会直接变成完成状态。

**想清空今天的次数。** 次数按自然日保存。换日后第一次打开会归零；同一天要清空，退出应用后删除上面的偏好文件。

**想看上一版源码。** 使用 Git 历史，例如 `git log -- main.swift` 和 `git show <提交>:main.swift`。
